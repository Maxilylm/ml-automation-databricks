# ml-automation-databricks

Databricks ML automation. Spark MLlib, Delta Lake, Unity Catalog, MLflow integration, and Databricks deployment. Requires spark-core installed.

## Project tracking

This plugin's work is tracked in Jira project [PM3](https://blend360.atlassian.net/jira/core/projects/PM3/board). Filter the board by label `plugin:databricks` for this plugin's slice.
